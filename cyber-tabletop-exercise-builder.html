Running a tabletop with this tool

Twelve discussion-based scenarios personalised to the client's technology stack. Everything runs in this browser tab; nothing is uploaded.

⚠
Nothing is saved. The exercise lives in this tab only. Export the after-action report as PDF before closing the tab; the browser will warn you if you try to leave with exercise data.
Before the day
  1. Setup: client profile, technology stack, logistics and participants.
  2. Scenario library: choose a scenario. Brief & plan: confirm objectives, drop injects to fit the time available and set minutes per inject.
  3. Outputs: print the participant pack and facilitator guide; export slides as PDF or as a standalone HTML deck for the meeting-room PC.
On the day
  • Run exercise: start the clock, reveal injects, record decisions with rationale, and capture notes tagged as observation, decision, strength, gap or action.
  • Participant screen opens a second window for the projector that follows the injects you reveal. Present shows the full deck in this window.
  • Adaptive injects add pressure on demand and are logged automatically.
Afterwards
  • After-action review: rate each objective, turn tagged notes into strengths, gaps and actions, then export the report from Outputs.
