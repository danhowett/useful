How psparse works

Paste a PowerShell command, command line or script block. psparse peels obfuscation layer by layer (backticks, string reversal, -f format strings, char-code arrays, base64, gzip and deflate), explains each part, matches it against detection rules, extracts indicators and maps everything to MITRE ATT&CK Enterprise v19.2.

🔒
Safe by construction. The command is never executed. A Content-Security-Policy blocks every network request, results are rendered as plain text so a payload cannot inject markup, and nothing is written to browser storage (the theme choice lasts only for this tab).
Tips
  • Tick One command per line to triage many commands at once, e.g. a column exported from Event ID 4104 or 4688. Each appears in the session list.
  • Static decoding can be defeated by novel obfuscation. The ground truth is the script block logged by Event ID 4104.
  • The risk score adds severity weights (critical 10, high 6, medium 3, low 1). It ranks, it does not predict.
  • Add your own detections by extending the RULES array in this file.
