Comparing text

Paste or load two versions of a text: configuration files, scripts, logs, statements or policies. textDIFF matches them line by line, then highlights the exact words or characters that changed inside each modified line.

🔒
Nothing leaves this page. There are no network requests: no fonts, lookups or analytics. Compared text is kept in memory only and is cleared when you close the tab or press Clear.
Reading the results
  • Modified lines exist in both versions with edits; added and removed lines exist in only one.
  • Similarity is the share of characters the two texts have in common.
  • Use Characters highlighting to spot swapped digits in IPs, hashes, timestamps and paths.
  • Ignore whitespace and Ignore case hide cosmetic changes; the report records which settings were used.
Evidence integrity
  • Each loaded file gets a SHA-256 of its raw bytes; use this to identify the evidence item.
  • The text hash covers the UTF-8 text actually compared. Browsers convert CRLF line endings to LF, so it can differ from the file hash.
  • Editing a loaded file in the box is flagged on screen and in the report.
