Tools for incident response, readiness and threat intelligence.

Each tool is a single HTML file that runs entirely in your browser. Nothing is uploaded, so you can open them offline, from a USB stick or on an air-gapped analysis machine.

TRACE

v1.0

Threat Response & Case Evidence System

Case management for DFIR work. Log evidence with chain of custody and integrity hashes, track IOCs with ATT&CK tagging and automatic defanging, record response actions and regulatory notifications, and build a single incident timeline through to structured closure.

Drop the file onto a workstation, an analysis box or a USB stick and start logging straight away.

Aligned to
NIST SP 800-61 Rev. 3 and the NIST CSF 2.0 functions
Exports
Configurable incident report with colour palettes, CSV, STIX 2.1 and ATT&CK Navigator layer

New to TRACE? Load the sample case, a BlackCat/ALPHV ransomware incident on a finance file server, to see a fully worked investigation.

Download sample case
TRACE-CMS.html Standalone repo on GitHub Open TRACE

CIRA

v3.0

Cyber Incident Readiness Assessment

Tiered assessment across 8 domains and 40 controls, with sector overlays for 10 regulated industries, threat profiling, a maturity radar with peer benchmarking, improvement and retest tracking, 8 tabletop scenarios and a full PDF report.

Overlays
DORA, NCSC CAF, NIS2, DSPT, PCI DSS
cyber-readiness-assessment.html Open CIRA

NCSC CAF v4.0 Assessment

v3.0

Cyber Assessment Framework

Interactive assessment of all 41 contributing outcomes across the 4 objectives and 14 principles of CAF v4.0 (August 2025), with a risk matrix, improvement plan, maturity radar and exportable report.

Suits
CNI and essential-service self-assessment or assessor review
v3_NCSC-CAF-v4-Assessment-Tool.html Standalone repo Open CAF tool

Phishing Programme Maturity

v2.0New

Phishing programme assessment

Six dimensions and 35 controls, from governance and simulation quality to reporting culture, SOC integration and the technical defences around users. Sector and size set the expected tier, and anti-pattern checks flag practices that may be doing harm.

Aligned to
NCSC four-layer phishing guidance, NIST CSF 2.0, ISO/IEC 27002:2022
Exports
Full report, board summary, JSON and CSV
phishing-programme-maturity.html Open assessment

Tabletop Exercise Builder

v2.0New

Cyber tabletop exercises, from plan to report

Twelve incident scenarios personalised to the client's technology stack. Plan the run sheet, run the room with an exercise clock, decision log and a participant screen for the projector, then rate objectives and build the improvement plan.

Outputs
Slides (PDF or HTML), participant pack, facilitator guide, inject cards, after-action report
cyber-tabletop-exercise-builder.html Open builder

Notelet

Browser notebook

A tabbed notebook that lives in the browser. Notes stay open across sessions until you close them, a Stickies board keeps quick thoughts one click away, and you can search, sort and switch between serif and monospace writing fonts.

Saving
Autosaves locally, backs up to JSON, and on Chrome or Edge can autosave straight to a linked file on disk.
