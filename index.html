psparse

v3.0New

Offline PowerShell triage

Paste a PowerShell command, command line or Event ID 4104 script block. psparse peels base64, gzip, format-string, char-code and backtick obfuscation layer by layer, explains each part, scores it against 45 detection rules and maps it to ATT&CK v19.2, without ever executing it.

Safety Content-Security-Policy blocks all network access; nothing is stored
